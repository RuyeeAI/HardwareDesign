# DESIGN.md — P4C编译器项目说明 · 极简图纸白

## 风格声明

用户选定「B · 极简图纸白」：纸白底、蓝黑极简、克制留白、工程蓝图感。本项目为**技术评审文档型 deck**，走通用设计原则（未命中学术/咨询/政务分支），显式声明**留白型**版面：内容页留白 25–30%（低于极简上限 35%），Hero/section 页 40–55%。

## 1. 画布与母版（三区，具体 px）

- 画布 1280×720，页面 padding：上 20 / 左右 70 / 下 20
- **A · 标题块**：y 20–110（高 90）——主标题 34px bold #1F2429，左对齐；标题下 2px #185FA5 短线（宽 56）
- **B · 内容区**：y 130–650（高 520）——一切正文/图表/卡片
- **C · 页脚条**：y 660–700——左「HardwareDesign · P4C」12px #6B7280，右页码 `NN / 14` 12px #6B7280
- 封面（P1）、section（P3/P7/P11）、结束页（P14）省略 A/B/C 分区，用自定义版式

## 2. 颜色系统（色彩池 ≤4 hex + 中性）

| 角色 | hex | 占比 | 用途 |
|---|---|---|---|
| 背景 | #FAFAF7 | 60–70% | 全部页面底色 |
| 墨色（主文本） | #1F2429 | — | 标题、正文 |
| 强调蓝 | #185FA5 | ≤10%（Hero 页可 15%） | 短线、关键数字、节点高亮、章节编号 |
| 灰（辅） | #6B7280 | ≤20% | 副文本、页脚、说明 |
| 中性 | #D9D9D2 / #FFFFFF | 剩余 | 细线、卡片描边、图表网格 |

- 渐变：**本项目禁用渐变**（极简图纸白，全部纯色平涂）
- 半透明：仅允许图表底纹 rgba(24,95,165,0.06)
- 色彩节奏：P5/P9/P12 为 peak 页，强调蓝占比可到 12–15%；其余内容页 ≤6%

## 4. 配图策略

- **全 deck 不使用照片/ImageGen**：技术评审场景，L1/L2 全部为**结构化 SVG**（架构图、时间轴、数据流图、条目编码图、sV 链示意、大字数字）——属设计原则允许的 SVG 白名单（架构图/流程图/时间轴/巨型数字/图表底图）
- SVG 统一风格：2px 线宽、#1F2429 线 + #185FA5 高亮节点 + #D9D9D2 辅助线、无渐变无阴影、直角优先（圆角仅 4px）
- L3 母版徽标：16×16 蓝色方点 + 右侧「P4C」11px，内容页页脚左侧，全篇位置一致

## 5. 密度与容器

- 正文最小 15px；内容页字数下限 150（见 STORY 各页 density）
- 卡片描边 1px #D9D9D2、直角（极简）、内边距 20–24、无阴影
- 横向兄弟卡尾部元素 y 对齐；底栏锚定用 space-between
