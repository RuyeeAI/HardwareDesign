# io/ — 主机侧（生成期）工具

> 路径：`src/main/scala/BaseCbb/io/`　包：`BaseCbb.io`　文件 4 个：FileIO / JsonTools / SeededRandom / SimpleProduct

本目录全部为 **Scala 主机侧工具**（生成期代码，不产生硬件），供构建脚本、测试与代码生成使用。
与 `misc/utils.scala`（GenProcessBuilder 等）同类，建议合并归口。

---

## 1. FileIO.scala

| 对象方法 | 功能 | 注意 |

| `ReadFile(file): Seq[String]` | 读文本文件全部行 | ⚠ **未关闭 Source（资源泄漏）** |

- `:33-44`：`JsonMapTool` 整段注释死代码（Map↔JSON 未完成设想），建议删除或补齐。

## 2. JsonTools.scala — JSON 读写

| 方法 | 功能 | 注意 |
|------|------|------|
| `saveAsPrettyJsonFile(fileName, json)` | json4s parse→pretty→写盘 | 依赖 json4s |
| `jsonStr2Map(json)` | `extract[Map[String,Any]]` | |
| `jsonStr2List(json)` | `extract[Seq[Any]]` | |
| `scalaTypetoJson(query)` | **手写** JSON 序列化 | ⚠ **无任何转义**（键/值含 `"`/`\` 即产生非法 JSON）；`case e:Enumeration` 分支不可达 |
| `saveMap2JsonFile(fileName, query)` | 组合上述 | |

- ⚠ `import org.json4s.native._` 未使用（实际用全限定 `JsonMethods._`）。
- 建议：手写序列化换成 json4s 完整实现（`Extraction.decompose`），消除转义缺陷。

## 3. SeededRandom.scala — 生成期确定性 PRNG

```scala
object SeededRandom { val fromSeed = new scala.util.Random(42) }
```
- 用途：让硬件生成**可复现**（Random.nextInt 会破坏复现性）。
- ⚠ 命名 `fromSeed` 暗示可传种子，实为固定 42；建议 `def apply(seed: Int = 42)`。

## 4. SimpleProduct.scala — 结构化相等混入

```scala
trait SimpleProduct extends Product with Equals
```
- 提供 `equals`（canEqual + productIterator 逐字段比较）、`hashCode`（`MurmurHash3.productHash`）、`toString`。
- 使用方需自行实现 `canEqual/productPrefix/productArity/productElement`；用于无法用 case class 的场景。
- 与 case class 生成的相等语义等价。

## 设计注意

1. `ReadFile` 资源泄漏、`JsonTools` 无转义 —— 两个真实缺陷，建议修复。
2. `misc.GenProcessBuilder`（进程启动）与 `io.FileIO/JsonTools`（文件/JSON）同属主机侧工具，建议统归 `BaseCbb.io`（或新建 `BaseCbb.host`）并整理文档。
3. 无专门测试文件（JsonTools 可在 `runMain` 或 build 脚本中验证）。
