# RegCbb_v2 寄存器编写指导

> 本文档指导如何用 RegCbb_v2 定义芯片寄存器文件、自动生成 RTL/文档，以及**如何把外围逻辑（用户逻辑）方便地连接到寄存器上**。
> 完整可运行示例见 `../src/main/scala/BaseCbb/RegCbb_v2/demo/UartDemo.scala`。

---

## 1. 三步工作流

```
① 定义（单一事实源）  →  ② 生成（RTL + 连接视图）  →  ③ 连接外围逻辑 + 输出文档
  RegBlock("dev"){…}      AddressAllocator +            RegView 命名访问
  RegField.xxx(…)          RegFileTop / AxiLiteRegFile    EmitAll 一键生成
```

一份定义，同时产出：**RTL（Verilog）、用户连接视图、JSON、C 头文件、Markdown 寄存器手册**。硬件与文档永远一致，不存在漂移。

## 2. 定义寄存器（DSL）

### 2.1 寄存器块

```scala
import BaseCbb.RegCbb._
import BaseCbb.RegCbb.dsl._

val uart = RegBlock("uart") { b =>
  b.device("UART") // 生成物里使用的设备名（宏前缀、文档标题）
  b.baseAddress(0x40000000L) // 寄存器区基地址（字节地址）
  b.memBaseAddress(0x40001000L) // 存储器区基地址
  b.desc("UART 外设")

  b.reg("ctrl") { r =>
    …
  } // 定义寄存器
  b.mem("tx_fifo") { m =>
    …
  } // 定义存储器（直连端口）
}
```

### 2.2 字段（最小的定义单元）

```scala
b.reg("ctrl") { r =>
  r.desc("控制寄存器")
  r.group("control")                                 // 可选分组（文档用）

  // 便捷写法：RegField.<类型>(名字, 位宽, [复位值], [描述])
  r.field(RegField.rw("tx_en", 1, 0, "发送使能"))
  r.field(RegField.rw("baud_div", 12, 4, "波特率分频值"))

  // 全功能写法（描述/枚举/写动作）
  r.field(RegField("mode", 2) { f =>
    f.rw().reset(0).desc("工作模式")
    f.enum(0, "POLL", "轮询模式")
    f.enum(1, "IRQ",  "中断模式")
  })

  // 字段级 RO：混排在 RW 寄存器内
  r.field(RegField.ro("version", 4, 0, "硬件版本号"))
}
```

### 2.3 访问类型（8 种）与硬件语义

| 类型 | 软件可读 | 软件可写 | 硬件语义（外围逻辑看到/驱动什么） |
|---|---|---|---|
| **RW** | ✓ | ✓ | `wrEn`+`wrData` 写脉冲；`hwWrEn`+`hwWrData` 硬件直写；`value` 读当前值 |
| **RO** | ✓ | ✗ | 用户逻辑经 `field.roValue` 驱动，软件读回 |
| **WO** | 读回 0 | ✓ | `wrEn`+`wrData` 写脉冲（如 FIFO 写口、命令寄存器） |
| **RC** | ✓ | ✓ | 读后自动清零；硬件经 `hwSet` 置位 |
| **RS** | ✓ | ✓ | 读后自动全置 1；硬件经 `hwClr` 清除 |
| **W1C** | ✓ | ✓ | 写 1 清零；**硬件经 `hwSet` 置位**（中断状态寄存器首选） |
| **W1S** | ✓ | ✓ | 写 1 置位；硬件经 `hwClr` 清除 |
| **W1T** | ✓ | ✓ | 写 1 翻转；硬件经 `hwTog` 翻转 |

优先级（同一拍冲突）：**SW 写 > 读副作用（RC/RS）> 硬件 set/clr/tog**。

### 2.4 推荐命名约定

- 寄存器名用小写 + 下划线：`ctrl`、`status_ro`、`irq_w1c`、`tx_data_wo` —— 名字**无需**带类型后缀（类型由 `RegField.ro()` 等显式指定），但带上后缀可读性更好。
- 字段名同规则：`tx_en`、`baud_div`。
- 名字会被用于生成 Scala val 与 C 宏，请用合法标识符（字母/数字/下划线，不以数字开头）。

### 2.5 存储器

```scala
b.mem("tx_fifo") { m =>
  m.depth(64).dataWidth(64).sp()
    .atomic()        // 位宽 > 总线位宽时的原子访问（默认开启）
    .desc("64 位宽发送 FIFO")
  // 不指定 baseAddress：由 AddressAllocator 从块 memBaseAddress 起自动分配
  // 手工指定：m.baseAddress(0x5000_0000L)
}
```

存储器是一片**连续地址空间**，与寄存器挂在同一个总线接口下统一解码：
- **地址自动分配**：默认从块 `memBaseAddress` 起、按 `dataWidth/8` 字节自然对齐顺序分配；也可手工指定 `m.baseAddress(...)`（自动分配自动跳过已占用区域）；
- `dataWidth` 可为总线位宽（32）的整数倍（32/64/128/…）；
- 总线地址 = `baseAddress + 单元索引*dataWidth/8 + wordInUnit*4`；
- 用户侧逻辑挂 `io.memPorts.<名字>`（请求-响应协议，见 §4.6）。

### 2.6 RegBundle（GenBundle 风格）定义

v2 自包含实现了 Bundle 式定义（不依赖 v1 已删除的 GenBundle 基类）：

```scala
import BaseCbb.RegCbb.dsl._

class MyBundleRegs extends RegBundle {
  // 嵌套 RegBundle = 一个寄存器，内部字段按声明顺序 LSB-first 紧凑排列
  val bundle_ctrl = new RegBundle {
    val mode = UInt(2.W)
    val burst = Bool()
    Attr += (mode -> FieldAttr("工作模式", reset = 1)) // 描述/复位
    Attr += (burst -> FieldAttr("突发使能"))
  }
  // 寄存器名后缀推断访问类型（_ro/_wo/_rc/_rs/_w1c/_w1s/_w1t），
  // 该后缀成为寄存器内所有字段的默认访问类型
  val bundle_status_ro = new RegBundle {
    val link_up = Bool()
    Attr += (link_up -> FieldAttr("链路状态"))
  }
  // 叶子元素 = 单字段寄存器
  val bundle_scratch_ro = UInt(8.W)
}

// 转换并合入寄存器块（与字段级 DSL 汇合到同一 IR）
RegBlock("uart") { b =>
...
  b.regs(BundleToRegDefs.toRegDefs(new MyBundleRegs))
}
```

字段访问类型优先级：`FieldAttr.access`（显式） > 寄存器名后缀 > 字段名后缀 > RW。

## 3. 地址分配规则（AddressAllocator）

- 字段在寄存器内 **LSB-first 紧凑排列**（`tx_en` 占 bit0，`baud_div` 占 bit1..12，`version` 占 bit13..16）；
- **规则 3（占据位宽）**：
  - 寄存器总位宽 **≤ 32bit**：占据 32bit（1 word），有效数据**右对齐在低 bit 位**（`tx_en` 仍占 bit0）；
  - 寄存器总位宽 **> 32bit**：占据**能容纳其位宽的 2 的幂**宽度（如 40→64、96→128），
    **有效数据从高 bit 位开始放**（低 bit 位为 padding 0），字段位偏移从 `expandedBits - totalBits` 起；
- 寄存器按 **32bit word 对齐**：`wordCount = expandedBits/32`，`byteSize = wordCount*4`，任意寄存器不跨 word 边界；
- 地址 = `regBaseAddress + byteOffset`，解码用字节地址比较；**多字寄存器占 wordCount 个连续地址槽**。

**文档显示规则**：
- **位域图**：小端序，**左边=高 bit 位、右边=低 bit 位**（MSB-first）；
- **字段表格**：**先打印高 bit 位，再打印低 bit 位**（MSB-first）；
- **字节序**：**每 word（32bit）内部小端**（bit0=LSB）；**word 间顺序为大端**（低地址=高有效 word）。

控制台可打印布局：

```scala
println(AddressAllocator.summarize(map))
```

## 3.1 多字寄存器（>32bit）与原子性

寄存器位宽超过总线位宽（32）时，占 `wordCount` 个地址槽（wordCount 为 2 的幂，规则 3），两种访问模式：

| 模式 | 定义 | 硬件行为 | 软件访问协议 |
|---|---|---|---|
| **原子**（默认） | `r.atomic()`（或缺省） | 写低有效 word 进 shadow 暂存；**写最高有效 word（wordSel=0，低地址）时把完整值一次提交**；读任意 word 都返回已提交完整值的对应片段 | 写：先低有效 word 后高有效 word（最后一次写提交）；读：任意顺序 |
| **非原子** | `r.nonAtomic()` | 逐 word 直接写入对应位域，中间态可被读观测 | 逐 word 独立读写 |

> 例：40bit 寄存器占据 64bit（2 个 word，`byteSize=8`），数据占 bit[63:24]（规则 3）；
> word 间大端：`word0`（+0）= 最高有效 word（bit[63:32]），`word1`（+4）= 低 word（bit[31:0]）；
> 软件原子写：先写 `+4`（低 word）进 shadow，再写 `+0`（最高有效 word）提交 40bit 值。

```scala
b.reg("data64") { r =>
  r.desc("64 位原子寄存器")
  r.atomic()                                  // 默认即原子，可省略
  r.field(RegField.rw("value", 64, 0, "64 位数据"))
}
b.reg("data64_plain") { r =>
  r.desc("64 位非原子寄存器")
  r.nonAtomic()
  r.field(RegField.rw("value", 64, 0, "64 位数据"))
}
```

用户侧 `value`/`wrData` 始终是全宽（64bit），不受总线位宽限制。

## 4. 连接外围逻辑（核心）

### 4.1 三步连接

```scala
import BaseCbb.RegCbb.hw._

val map = AddressAllocator.allocate(uart)

// 简单总线版（wr/rd/addr/wdata/rdata 单拍）
val regFile = Module(new RegFileTop(map))
// 或 AXI4-Lite 版（io.axi 为从设备接口）
// val regFile = Module(new AxiLiteRegFile(map))

// 连接视图：命名访问 + 自动位域切割；未驱动的输入自动置 DontCare
val regs = RegView(map, regFile)
```

### 4.2 写侧（软件 → 外围逻辑）

**捕获式（最常用）**：`wrEn` 为写脉冲（一拍），`wrData` 为同拍数据（已寄存，与 `wrEn` 对齐）：

```scala
when(regs("tx_data_wo").wrEn) {
  txByte := regs("tx_data_wo").field("data").wrData   // 自动按字段位域切割
}

// 寄存器级捕获
val ctrlReg = RegInit(0.U(4.W))
when(regs("ctrl").wrEn) { ctrlReg := regs("ctrl").wrData }
```

**读当前值**（RW/W1C/RC 等）：`value` 输出当前寄存器内容，无需自己维护副本：

```scala
val baud = regs("ctrl").field("baud_div").value
```

**硬件直写 RW**（外围逻辑更新寄存器，如计数/自动配置）：

```scala
regs("ctrl").hwWrEn := hwUpdatePulse
regs("ctrl").field("baud_div").hwWrData := autoBaud
```

### 4.3 读侧（外围逻辑 → 软件）

**RO 字段/寄存器**：直接对 `field.roValue`（真实端口）赋值：

```scala
regs("status_ro").field("tx_busy").roValue := txBusy
regs("status_ro").field("tx_done").roValue := RegNext(donePulse, false.B)
regs("rx_data_ro").field("data").roValue  := rxByte
```

**RC/RS 读通知**：`rdEn` 在读操作下一拍拉高，`rdData` 为读到的值（读副作用发生前），用于同步清除外围逻辑侧状态。

### 4.4 中断（硬件置位 → 软件清除）

```scala
// 硬件侧：事件脉冲置位 W1C 位（电平或，置位后保持，直到软件写 1 清除）
regs("irq_w1c").field("tx_done").hwSet := txDonePulse
regs("irq_w1c").field("rx_rdy").hwSet  := rxRdyPulse

// 中断输出 = 状态 & 使能
io.irq := (regs("irq_w1c").value(0) && regs("irq_en").field("tx_done").value(0)) ||
          (regs("irq_w1c").value(1) && regs("irq_en").field("rx_rdy").value(0))
```

W1S 用 `hwClr`（硬件清除、软件写 1 置位），W1T 用 `hwTog`。

### 4.5 字段级与寄存器级 API 速查

```scala
// 寄存器级
regs("ctrl").wrEn / wrData / rdEn / rdData / value / hwWrEn

// 字段级（自动位域切割，位宽 = 字段位宽）
regs("ctrl").field("baud_div").wrData    // SW 写入值切片
regs("ctrl").field("baud_div").value     // 当前值切片
regs("ctrl").field("version").roValue    // RO 驱动端口（可 :=）
regs("irq_w1c").field("tx_done").hwSet   // 置位端口（可 :=）
regs("irq_w1c").field("tx_done").hwClr   // 清除端口
regs("ctrl").field("baud_div").hwWrData  // HW 直写数据端口

// 按类型批量迭代
regs.writableRegs.foreach(r => r.fields.foreach(f => when(f.wrEn) { … }))
regs.roRegs / regs.readNotifyRegs
```

### 4.6 Memory 地址空间与外部 SRAM（请求-响应协议）

寄存器与 memory 通过**同一个总线接口**连接（`RegFileTop` 统一解码）；memory 对用户侧逻辑暴露**请求-响应**接口 `io.memPorts.<名字>`：

```
读请求（RegFileTop → 用户侧）：rd（电平，ack 未返回前一直拉高）+ raddr
写请求（RegFileTop → 用户侧）：wr（电平，用户侧未返回 ack 前一直拉高）+ waddr + wdata
响应（用户侧 → RegFileTop）：rdata + ack（用户侧获得带宽/完成后，同拍置起）+ status[2:0]
```

**status 编码（`hw.MemStatus`）**：

| 编码 | 含义 |
|---|---|
| `000` (OK) | 读数据 OK / 写操作完成 |
| `001` (TIMEOUT) | 超时（读或写） |
| `010` (UNCORRECTABLE) | 读数据不可纠正错误 |
| 其余 | 保留 |

用户侧逻辑（外部 SRAM 包装）典型实现：

```scala
val sram = Mem(64, UInt(64.W))
val mp = regFile.io.memPorts.elements("tx_fifo").asInstanceOf[MemPortIO]

when(mp.wr) { sram.write(mp.waddr, mp.wdata) }        // 写（wr 保持期间）
mp.rdata := sram.read(mp.raddr)                       // 读（raddr 在请求期间保持）

// 零延迟响应：获得带宽/完成即同拍返回 ack
mp.ack := mp.rd || mp.wr
mp.status := MemStatus.OK
// 延迟响应（如多周期 SRAM）：mp.ack := ShiftRegister(mp.rd || mp.wr, N, false.B, true.B)
// 错误上报：mp.status := Mux(err, MemStatus.UNCORRECTABLE, MemStatus.OK)  // 非 OK 数据无效
```

总线访问（32bit）行为（每 memory 一个内部状态机，rd/wr 电平保持直到 ack）：
- `dataWidth == 32`：写为 wr 请求（等 ack），读为 rd 请求（等 ack）；
- `dataWidth == 64/128/…` 且**原子**：写低字进内部 shadow SRAM（无需用户侧），写最高字时合并一次提交（wr 请求）；
- `dataWidth == 64/128/…` 且**非原子**（`m.nonAtomic()`）：内部"读-改-写"状态机（rd 请求 → 等 ack → 合并 → wr 请求 → 等 ack）；
- 读回：ack 拍数据有效，status 非 `OK` 时总线读回 0（数据无效）；状态机 busy 期间的新总线访问会被忽略，软件须等上一次访问完成（简单总线为脉冲式，无 in-flight 保护）。

### 4.7 生成具名视图类（可选升级）

`gen.ViewSourceGen` 可从 IR 生成一个 Scala 类，把字符串键访问升级为编译期具名访问：

```bash
# EmitAll 已生成 generated/RegCbb_v2/UartRegs.scala，加入工程后：
val regs2 = new UartRegs(RegView(map, regFile))
when(regs2.tx_data_wo.wrEn) { txByte := regs2.tx_data_wo.field("data").wrData }
```

字段名拼错、寄存器不存在都会在**编译期**报错。

sbt "runMain BaseCbb.RegCbb_v2.demo.EmitAll"   # 输出到 generated/RegCbb_v2/

## 6. 常见问题与限制

| 问题 | 说明 |
|---|---|
| 寄存器位宽 > 32 | 多字寄存器自动占 wordCount 个地址槽；原子模式写最高字一次提交，非原子模式逐字直接写（见 §3.1） |
| 同寄存器多个 RO 字段 | 每个字段是独立端口，分别 `:=` 驱动即可（v2 相对 v1 的关键改进） |
| 同寄存器多字段 HW 置位 | W1C 字段各自独立 `hwSet` 端口，互不干扰 |
| AXI 包装器 | 单笔在途事务（aw 后 w 到达）；读返回 1 拍延迟；不支持 burst（后续版本） |
| 存储器访问 | 与寄存器共用总线解码；`dataWidth` > 32 时原子（shadow 提交）或非原子（RMW），见 §4.6 |
| 未使用的中断/RO 端口 | 无需处理，`RegView` 已自动置为 DontCare |
| 与 v1 (RegCbb) 的关系 | v2 独立、自包含；不依赖 v1 的 `GenBundle`/`fldAttr`（其源文件已被删除）；`RegBundle` 为自实现的等价物 |
