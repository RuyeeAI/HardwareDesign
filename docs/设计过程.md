# Memory

* 为SpMemoryWrap3增加如下功能：

  * 与CPU的接口参考MemoryRsPort

  * CPU asserts write or read enable and relevant address and data to MemoryWrap3, when the logic is also operating the memory in the same cycle, user logic get high priority and operate the memory, the access from CPU waits for a IDLE cycle  which user logic is idle and get the time slot to operate the memory

  * if CPU has been waiting for IDLE cycle for more than CpuCfgIdleCycleTh0 cycles which is configurable, the CPU asserts a backpress to user logic and wait for IDLE cycle again, if CPU wait for IDLE cycle for more than CpuCfgIdleCycleTh1 cycles which is configurable，则返回一拍脉冲ACK= 1， 读数据全1，status = 3，写成功或着读数据完成时返回ACK

  * 如果读memory数据发生不可纠错误，则返回读数据时Status置1；

  * ACK返回后若干拍（取决于路径延时，typical <20cc）CPU会将write/read enable拉低结束本次访问
